# Yeti Insurance Agency: Website

A fast, SEO-first static website for **yetiinsu.com**.

- Every page is plain HTML, generated by a small build script.
- There are no frameworks and no dependencies; only Node.js 18 or newer is required.

## Quick start

**Easiest:** on a Mac, double-click `start-mac.command`; on Windows, double-click `start-windows.bat`. It builds the site, starts a local server and opens **http://localhost:8080** in your browser. You need [Node.js](https://nodejs.org) (LTS version) installed.

On a Mac, the first time you open `start-mac.command` you may need to right-click it → *Open* → *Open*, because macOS blocks downloaded scripts by default.

From a terminal:

```bash
npm run dev       # local server at http://localhost:8080, rebuilds automatically when you edit files in /src
npm run build     # builds the production site into /dist (and site-preview.html)
```

**Forms work locally.** Every quote, claim or service request you submit is saved to `/submissions/` and listed at **http://localhost:8080/_submissions**. This lets you test the full flow before going live. The `_submissions` page only exists on your computer and is never uploaded.

**To preview without a server, open `preview/index.html`.** Double-click it and it opens in your browser. This copy uses relative links so it works straight from your computer, and its forms simulate a successful submission.

Don't upload `/preview` to your host. Use `/dist`, which has search-engine-friendly URLs.

To deploy, upload the `/dist` folder to any static host. Netlify is recommended; see Deployment below.

## SEO built in

- **Titles and descriptions:** every page has a unique title (under 70 characters) and meta description (70–165 characters), one H1, a canonical URL, and Open Graph tags.
- **Structured data (JSON-LD):**
  - `InsuranceAgency` on every page: address, phone, hours, area served (Texas), founding date, and social profiles.
  - `BreadcrumbList` on all inner pages.
  - `Service` on each coverage page.
  - `FAQPage` on pages that have FAQs.
  - `Article` on each resource post.
  - Team members as `Person` entries.
- **Fully rendered pages:** all content is in the page HTML. Nothing depends on JavaScript to appear, so search engines see everything.
- **Internal linking:** coverage hubs link to their product pages, product pages link to related coverage, and articles link to the matching coverage page.
- **Self-rating left out on purpose:** we do not add a self-declared `aggregateRating`, because Google ignores star ratings that a business publishes about itself.

## Forms

The site has three forms: `quote`, `claim-notice` and `service-request`.

- **On Netlify (default):** form submissions are captured automatically. To get email alerts, go to Netlify → *Forms* → *Form notifications* → add an email notification for each form.
- **On other hosts:** set `formEndpoint` in `src/site.js` to a Formspree (or similar) URL, then rebuild.

All three forms have a spam honeypot and field validation. If a submission fails, the visitor sees an error message with the phone number.

## Deployment (Netlify)

1. Create a site at netlify.com. Either drag in the `dist` folder, or connect a Git repository (the build settings are already in `netlify.toml`).
2. Under *Domain settings*, point `www.yetiinsu.com` to Netlify and enable HTTPS.
3. Set up Netlify form notifications, as described under Forms.
4. Submit `https://www.yetiinsu.com/sitemap.xml` in Google Search Console.

## After launch: ranking plan

1. **Google Business Profile:** choose the primary category "Insurance agency," add photos, post monthly, and reply to every review.
2. **Reviews:** ask every new client for a Google review.
3. **Content:** publish two Texas-focused articles a month, each linking to a coverage page.
4. **City pages:** add pages for cities where you have real clients, with unique local content only.
5. **Citations:** list the agency in Yelp, BBB, carrier "find an agent" directories and local chambers of commerce, with the same name, address and phone.
